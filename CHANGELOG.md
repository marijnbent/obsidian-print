# Changelog

## 0.6.5 - 2026-09-05

- Load custom print CSS directly from the file on each print.
- Add a snippets-folder button and clearer custom CSS setup guidance.
- Explain missing CSS files and doubled file extensions.

## 0.6.4 - 2026-09-03

- Added printing for multiple notes selected in the File Explorer.
- Extended the combine-notes setting to selected notes.

## 0.6.3 - 2026-08-29

- Simplified iOS PDF byte handling.
- Removed duplicate Mermaid print styles.

## 0.6.2 - 2026-08-29

- Fixed long properties sections leaving a blank first page.

## 0.6.1 - 2026-08-28

- Fixed the desktop print dialog on Obsidian 1.13.
- Removed hidden print frames after failures and canceled print jobs.

## 0.6.0 - 2026-08-28

- Improved security and compatibility with Obsidian's plugin guidelines.
- Added searchable settings on Obsidian 1.13 and later.
- Replaced desktop and iOS print internals with script-free print flows.
- Fixed custom CSS support for renamed configuration folders.
- Added release artifact attestations and network-use documentation.
