# Contributing

Thank you for helping to improve Print.

## Report a problem

Search the existing issues first. If the problem is new, use the bug report template. Include your Obsidian version, operating system, plugin version, and the smallest note or CSS example that shows the problem. Remove private vault data before you attach files.

## Make a change

1. Install Node.js 24 and run `npm ci`.
2. Make a focused change.
3. Run `npm run lint`, `npm test`, and `npm run build`.
4. Open a pull request that explains the user-visible result.

Keep changes small, typed, and compatible with the minimum Obsidian version in `manifest.json`.
